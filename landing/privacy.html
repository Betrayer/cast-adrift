Privacy & License

Last updated: 30 July 2026.

What is stored

  • On your device — settings, meta progress and the current run, in localStorage. Clearing site data erases all of it.
  • In the cloud (Firebase Firestore) — the same meta progress and one run snapshot, so a run continues on a second device; leaderboard entries you submit; nothing else.
  • Identity — an anonymous Firebase account on the web. Inside Telegram, your numeric Telegram id becomes the account id (tg:<id>) and your first name is used as the leaderboard display name. No email, no phone number, no contacts.
  • Diagnostics — anonymous gameplay counters (a run started, a node cleared, a death) and, if the game crashes, the error message with the screen it happened on and the build version. Rate limited to a handful per session.

What is never stored

No advertising identifiers, no cross-site tracking, no third-party analytics beyond Firebase, and nothing is sold or shared. There is no payment of any kind in this version.

Erasing your data

Clear the site data in your browser to remove the local copy. To remove the cloud copy and any leaderboard entry, write to bohdan@ranktracker.com from the Telegram account in question, or send /delete to the bot; the documents are deleted within seven days.
